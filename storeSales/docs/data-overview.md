# Store Salesのデータ概要

## 予測するもの

エクアドルの小売チェーンFavoritaについて、**日付 × 店舗 × 商品カテゴリごとの販売数量**を予測する。金額や利益、個々の商品の売上ではない。重量で販売する商品があるため、salesは小数を含む。

手元のデータは54店舗・33カテゴリの1,782系列。学習期間は2013-01-01〜2017-08-15、予測期間は2017-08-16〜2017-08-31の16日間。28,512行の `id,sales` を提出する。評価指標はRMSLEで、小さいほど良い。

公式Dataページの説明には15日という表記があるが、ここではCSVに実際に含まれる16日を記載している。

## CSVの役割

| CSV | 粒度・内容 | 行数 |
|---|---|---:|
| train | 日付×店舗×カテゴリ。salesが正解、onpromotionは販促対象の商品数 | 3,000,888 |
| test | 同じ粒度の予測対象。salesなし、販促数あり | 28,512 |
| sample_submission | 提出IDと列形式の見本。salesの0は正解ではない | 28,512 |
| stores | 店舗の都市・州・タイプ・cluster | 54 |
| transactions | 日付×店舗の取引件数。最終日は2017-08-15 | 83,488 |
| oil | 原油価格。予測期間の日付も含む | 1,218 |
| holidays_events | 祝日・イベント・振替など。国・地域・都市の区別あり | 350 |

祝日はlocale・locale_nameで該当店舗を判断し、transferredやTransfer等も区別する。日付だけで結合すると、重複するイベントにより行数が増える場合がある。

## 実データの特徴

- **ゼロ売上は31.30%**。ゼロが多いカテゴリと、通常よく売れるカテゴリを分けて観察する価値がある。
- 売上の中央値は11、95パーセンタイルは1,965、99パーセンタイルは5,507、最大は124,717。分布は強く右に偏っている。
- 上位5カテゴリが販売数量合計の78.72%を占める。ただし数量には個数・重量が混在し、これは売上金額の構成比ではない。RMSLEも数量合計に比例して行を重み付けする指標ではない。
- 学習CSV内の店舗・カテゴリ・日付の重複は0。セルの欠損は原油価格に3.53%ある。
- 学習CSVには2013〜2016年の12月25日の行自体がない。欠測行をゼロ販売と同一視しない。ラグを作るときは行数と暦日を区別する。
- 2016年以降の行単位では、salesとonpromotionのPearson相関は0.55。
- 2016年以降、外部データが揃う407日の日次集計では、salesと取引件数のPearson相関は0.74、販促数とは0.42、原油価格とは0.23。

相関は店舗・カテゴリ構成、曜日、季節、成長傾向などの影響を受ける。販促が売上をどれだけ増やしたかという因果効果は、この集計だけでは分からない。日次の取引件数合計も、提供された店舗の観測値を集計したもので、店舗の欠測を補完していない。取引件数の未来実績は提供されていないため、そのまま未来の特徴量として使えない。

## モデル改善に向けた確認候補

まず検証期間を複数にして、店舗・カテゴリ別、ゼロ売上/正の売上別の誤差を比較する。販売数量の大きいカテゴリだけでなく、RMSLEが悪化している系列を特定する。曜日・販促の関係が系列ごとに異なるかも確認する。

この概要は記述統計であり、LightGBMのKaggleスコア悪化の原因を確定するものではない。
